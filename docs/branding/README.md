# TurboFetch brand assets

The approved identity is **Modern & Clean**: an angular cyan/electric-blue speed mark, white-and-blue TurboFetch wordmark, and dark navy base.

## Palette

- Background: `#0B1420`
- Cyan: `#08B8F2`
- Bright cyan: `#08C8E8`
- Electric blue: `#087CF4`
- Wordmark white: `#F7FAFF`

## Assets

- `turbofetch-logo.svg`: scalable full wordmark and tagline for documentation, splash/marketing surfaces, and repository presentation.
- Android launcher resources: `app/src/main/res/mipmap-anydpi*/ic_launcher*.xml`
- Shared vector mark: `app/src/main/res/drawable/ic_turbofetch_mark.xml`

The tagline is “FASTER · SMARTER · DOWNLOADS”. For small app icons, use the symbol only; do not squeeze the wordmark or tagline into the launcher icon.
